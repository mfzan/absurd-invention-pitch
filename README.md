A one-sentence pitch for a ridiculous invention that fixes a tiny everyday annoyance: a smoke detector that files a formal noise complaint against your toast and summons the toaster to a hearing before it is allowed to beep again. Running `main.py` writes that single sentence (144 characters) to `entry.txt` in the output directory.

## Run it

```sh
python3 main.py
```
